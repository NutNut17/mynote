## Anchors

| Regex | Description                                                      |
| ----- | ---------------------------------------------------------------- |
| `^`   | Start of line/string                                             |
| `$`   | End of line/string                                               |
| `\b`  | Word boundary (position between a word char and a non-word char) |
| `\B`  | Not a word boundary                                              |

## Characters

Regex,Description
.,Any character except newline
| Regex | Description |
| ----- | ----------- |
| `.` | Any character except newline |
| `\d` | Any digit [0-9] |
| `\D` | Any non-digit |
| `\w` | Word character (alphanumeric + underscore) [a-zA-Z0-9_] |
| `\W` | Non-word character |
| `\s` | "Whitespace (space, tab, newline)" |
| `\S` | Non-whitespace |

## Quantifiers

| Regex   | Description                                    |
| ------- | ---------------------------------------------- |
| `*`     | 0 or more                                      |
| `+`     | 1 or more                                      |
| `?`     | 0 or 1                                         |
| `{n}`   | Exactly n                                      |
| `{n,}`  | n or more                                      |
| `{n,m}` | Between n and m                                |
| `*?`    | Lazy match (stops at the first possible match) |

## Set and Ranges

| Regex      | Description                             |
| ---------- | --------------------------------------- |
| `[abc]`    | Matches a, b, or c                      |
| `[^abc]`   | Matches any character except a, b, or c |
| `[a-z]`    | Any lowercase letter                    |
| `[A-Z]`    | Any uppercase letter                    |
| `[0-9]`    | Any digit                               |
| `[a-zA-Z]` | Any letter                              |

## Groups and Logic

| Regex            | Description                                                     |
| ---------------- | --------------------------------------------------------------- | --------------------------- |
| `(abc)`          | Capture Group: Matches abc and remembers it                     |
| `(?:abc)`        | Non-Capture Group: Matches abc but doesn't store it             |
| `(a              | b)`                                                             | Alternation: Matches a or b |
| `\1`, `\2`, etc. | Backreference: Matches the exact text found in Capture Group #1 |

## Lookarounds

| Regex      | Description                                        |
| ---------- | -------------------------------------------------- |
| `(?=abc)`  | Positive Lookahead: Match if abc follows           |
| `(?!abc)`  | Negative Lookahead: Match if abc does not follow   |
| `(?<=abc)` | Positive Lookbehind: Match if abc precedes         |
| `(?<!abc)` | Negative Lookbehind: Match if abc does not precede |

## Flags

| Flag | Description      | Meaning                                                             |
| ---- | ---------------- | ------------------------------------------------------------------- |
| `g`  | Global           | Find all matches, not just the first one.                           |
| `i`  | Case-insensitive | Match regardless of case (e.g., `a` matches `A`).                   |
| `m`  | Multiline        | Treat `^` and `$` as start/end of lines, not just the whole string. |
| `s`  | Dotall           | Allow `.` to match newline characters (which it normally doesn't).  |

## Application

Match an Email: `^[\w\.-]+@[\w\.-]+\.\w{2,}$`

Match a URL (Simple): `https?:\/\/(www\.)?[-a-zA-Z0-9@:%._\+~#=]{1,256}`

Find Duplicate Words: `\b(\w+)\s+\1\b`

## Example

Find this pattern: `/^::mermaid\s*\{[^}]*name="([^"]+)"[^}]*\}\s*\n([\s\S]*?)\n::/gm`

```mdc
::mermaid { name="MyFlowchart" priority="high" }
graph TD
    A[Start] --> B[End]
::
```

| Component    | Meaning                                                                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `/ ... `/    | Delimiters that mark the beginning and end of the regex.                                                                                                                             |
| `^`          | Anchor: Matches the start of a line (thanks to the m flag).                                                                                                                          |
| `::mermaid`  | Literal: Matches the exact text ::mermaid.                                                                                                                                           |
| `\s*`        | Quantifier: Matches any number of whitespace characters (spaces, tabs).                                                                                                              |
| `\{`         | Escaped Character: Matches a literal {. Braces have special meaning in regex, so we use \ to ""escape"" it.                                                                          |
| `[^}]*`      | Negated Character Class: Matches any character except }. This skips over any attributes inside the braces until it finds the name.                                                   |
| `"name="""`  | Literal: Matches the text name="".                                                                                                                                                   |
| `"([^""]+)"` | Capture Group 1: Matches one or more characters that are not a quote (""). This extracts the actual name value.                                                                      |
| `"""`        | Literal: Matches the closing quote.                                                                                                                                                  |
| `[^}]*`      | Negated Class: Skips any remaining attributes until the closing brace.                                                                                                               |
| `\}`         | Literal: Matches the closing }.                                                                                                                                                      |
| `\s*\n`      | Matches any trailing spaces followed by a newline.                                                                                                                                   |
| `([\s\S]*?)` | Capture Group 2 (The Content): [\s\S] is a trick to match any character including newlines. The \*? makes it lazy, meaning it stops as soon as it sees the next part of the pattern. |
| `\n::`       | Matches a newline followed by the closing ::.                                                                                                                                        |
| `gm`         | Flags: g (Global) finds all matches in the text. m (Multiline) allows ^ to match the start of every line, not just the very beginning of the file.                                   |
