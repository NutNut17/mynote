## Minecraft Graphics

- Minecraft uses LabPBR as the format for PBR textures
- MER Map (Metallic (red), Emissive (green), Roughness (blue)). 
- States of surface: opaque, cutout(hole), transluctent(water), PBR, 3D

## Game Optimizer

### Optifine

Legacy monolithic optimizer. Pioneered shaders.

### Sodium

A mod built on top of Fabric modding loader framework. Community open source optimizer. Work together with Iris mod for shader. Brings extreme optimization.

- VBO (Vertex Buffer Object): Slow manual sequentual pipeline command by CPU.
- MDI (Multi-Draw Indirect): Quicker parallel runs. GPU decides where to render.

### Minecraft 26

With Minecraft coming engine update from OpenGL to Vulkan. A new modding tech is coming. This update will optimize the game, previouslly the game focus on single CPU core, coming updates will leverage multi-core CPUs.
