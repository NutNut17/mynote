# AWS

IAM = Identity and Access Management. It's AWS's system for controlling who can do what inside your AWS account.

A Role is like a temporary ID badge that AWS services wear when they need to do things on your behalf.

Always use the same region consistently.

```
Root Account  ← master key, use only for setup
    ↓ creates
IAM Admin User  ← your daily driver
    ↓ creates
Roles/Policies for services (Amplify, etc.)
```

```
IAM Account
├── Users (people)        → you, your teammates
├── Groups (collections)  → "developers", "admins"
├── Roles (for services)  → Amplify, Lambda, EC2
└── Policies (rules)      → attached to any of the above
```

## Cloudwatch

CloudWatch is AWS's central monitoring and logging service. Everything that runs in AWS can send data there.

```
Any App
      ↓
Lambda function runs
      ↓
Logs every request/error → CloudWatch Logs
Metrics (CPU, memory)   → CloudWatch Metrics
Alarms (if error > 10x) → CloudWatch Alarms
                                ↓
                        Email/SMS/Slack alert
```
