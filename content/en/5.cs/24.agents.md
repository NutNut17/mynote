- Hardware Orchestration
- Configured models
- API and tools parity
- Slow, poor concurrency, no UI

- llama.cpp is the engine, can run directly for speed
- vLLM for GPU data center, while llama.cpp is for pc
- GGUF (GPT-Generated Unified Format) file is a single, optimized binary container format designed to store and run LLM like Llama or Mistral.
- GGUF Quantization Q4_K_M: 4 bit-depth (avg bits per weight), K-Quant method (advanced mixed-precision), Medium size
- LM Studio: a closed-source UI app of ollama-counterpart 

### Hosting LLMs

- Hosted as a process on a port
- LiteLLM: Provide API, rate limiting, routing, dashboard. Filled Ollama's weakness
- Ollama and LiteLLM handle request sequently

### OpenClaw

![OpenClaw](/images/cs/ai/openclaw-color.svg){width="192" class="mx-auto block bg-white p-4 rounded-xl my-8"}

| ARCHITECTURE | Sample |
| - | - |
| USER INTERFACE | WhatsApp, Telegram, Signal, Discord, iMessage |
| CONTROL PLANE | The Gateway Daemon (Handles routing & sessions) |
| REASONING CORE | LLM (Claude 3.5, GPT-4o, Gemini Pro, or Local LLM) |
| EXECUTION LOOP | Tools (Bash, Browser, File Read/Write, MCP) |
| STATE & MEMORY | `~/.openclaw/` (Plaintext Markdown / YAML files) |

- Uses HEARTBEAT.md to wake periodically
- Uses SOUL.md to remember things

### Agentic AI Workflow Review

| Method | Description | Sample |
| - | - | - |
| IDE | An app with agentic model and app's unique feature | VS Code, Cursor, Antigravity |
| Terminal | Interacts with agentic model solely on terminal | Claude Code, OpenCode (Similar to CC and are opensource) |
| VS Code Extension | A chat panel in VS Code that enable interaction with agentic model |

My best experience us using Claude Code extension on VS Code for a diff view, manageable screen. I will use Claude Code CLI only when connecting to external device.
