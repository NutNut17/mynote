### Tip

::tip{to="https://ui.nuxt.com/getting-started/icons/nuxt#theme"}
Icons are already defined by default, but you can customize them in your `app.config.ts`:

```ts [app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      codeIcon: {
        terminal: "i-ph-terminal-window-duotone",
      },
    },
  },
});
```

## Custom Components

### Icon

In the Docus and Nuxt UI ecosystem, icons are powered by Iconify. It's coded as `i-<source>-<icon-name>`. In default, nuxt use lucide icons. We can add custom icons by configuring `nuxt.config.ts`. View [Icones](https://icones.js.org/) to view all available icons.

| Icon Name         | Icon                          |
| ----------------- | ----------------------------- |
| `i-lucide-github` | :icon{name="i-lucide-github"} |
| `i-mdi-github`    | :icon{name="i-mdi-github"}    |
| `i-logos-vue`     | :icon{name="i-logos-vue"}     |

## Styles on Markdown

The framework use standard tailwindcss for styling. Simply wrap the text with `[]` and add the style with `{}`. Example: `[styled text]{.text-primary.font-bold}`.
